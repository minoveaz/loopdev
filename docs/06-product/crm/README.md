## Regla de trabajo

Las definiciones, contratos, auditorias, handoffs y fixtures del CRM viven aqui por bloque de
producto. El codigo se desarrolla en ramas `feature/*-implementation` y debe leer el handoff del
bloque correspondiente antes de empezar.
