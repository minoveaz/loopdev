# LoopDev AI Skills Documentation

This directory contains reference material for the repository Skills. It is
not a second operational runtime or prompt framework.

## Active operational Skills

- [track-governance](../../.github/skills/track-governance/SKILL.md): tracks,
  scope, decisions, evidence, and lifecycle.
- [validation-framework](../../.github/skills/validation-framework/SKILL.md):
  validation selection and certification scope.
- [platform-shell](../../.github/skills/platform-shell/SKILL.md): shared shell
  composition and interaction contracts.
- [security-review](../../.github/skills/security-review/SKILL.md): RLS,
  organization isolation, contracts, migrations, and secrets.
- [git-workflow](../../.github/skills/git-workflow/SKILL.md): branch, commit,
  and pull request discipline.

These Skills are the only active operational authority.
